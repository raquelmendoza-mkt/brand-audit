## Consejos
- Usa `.jpg` y comprime cada foto por debajo de ~400 KB (ej. squoosh.app).
- Las fotos se recortan automáticamente al formato del recuadro, centradas.
- Las imágenes y el video de Brickell se cargan desde el CDN de Higgsfield. Si dejan de cargar, la sección muestra un fondo degradado animado; para fijarlas, descárgalas y cambia sus enlaces por `assets/carlos-visbal/<archivo>`.
- Para mantener el estilo minimalista: luz natural, colores neutros, sin textos encima.
- Si cambias un listing, edita la dirección y el precio en `carlos-visbal.html` (capítulo 05 · Portafolio) y reemplaza su foto.
